# Jackie Embroidery and Knitting

A front-end project built in **React.js** that showcases collections of handcrafted products, including embroidery, knitting, and amigurumi. This project combines modern design and functionality to elegantly showcase handmade pieces, ideal for a professional portfolio or as an online catalog.

---

## ✨ Features

- Image gallery of handcrafted products.
- Plans and collections section with featured prices.
- Responsive design for mobile and desktop devices.
- Reusable components: Header, Main, Footer, ProductDetail, Plans, Gallery.
- Use of CSS variables for color palettes, typography, and shadows.
- Buttons and cards with smooth hover animations.
